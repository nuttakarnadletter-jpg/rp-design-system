Global Structure

โครงสร้างไฟล์ที่ควรใช้เก็บ RP design system เพื่อเติมข้อมูลต่อเป็นระยะ

01 Foundation

Color, typography, spacing, radius, grid, elevation และ content token ที่เป็นพื้นฐานร่วมทุก product

02 Assets

Logo, icon, illustration, product mark และไฟล์ reference สำหรับ brand identity หรือ CI

03 Components

Button, input, select, card, table, modal และ navigation พร้อม state, variant และ usage note

04 Patterns

Form flow, empty state, error state, onboarding, dashboard layout และ reusable product patterns

05 Guidelines

Naming, accessibility, contrast, writing tone, token usage และ handoff checklist

06 Changelog

บันทึกการเพิ่ม ลบ แก้ token/component เพื่อให้ทีมตามเวอร์ชันและเหตุผลของการเปลี่ยนได้
